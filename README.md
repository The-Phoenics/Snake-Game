# Snake-Game

### A simple snake game written in C++

---

## Dependencies
- C++ compiler
- CMake >= 3.16


---

## Controls
- W key - Move Up
- A key - Move Left
- S key - Move Down
- D key - Move Right
- P key - Pause game
- Space - Start & resume Game

---

## Build

1. Clone repository `git clone https://github.com/Karansemwal/Snake-Game.git`
2. `cd Snake-Game`
3. `mkdir build`
4. Generate build `cmake -S . -B build`
5. Build project `cmake --build build`
